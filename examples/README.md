# Examples

Each recipe uses the public package API. Model weights and engine assets are not bundled with the package. Depending on the selected preset and source, loading may fetch model files or use files supplied by the application.

| Example                                                        | What it shows                                                                                           | Scope                                                                                          |
| -------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| [browser-microphone.ts](browser-microphone.ts)                 | Browser microphone capture and audio chunks for inference                                               | Browser permission and compatible model assets required                                        |
| [browser-file-transcription.ts](browser-file-transcription.ts) | Browser file decoding and PCM transcription                                                             | Browser file flow; assets depend on the selected source                                        |
| [transcribe-canonical.ts](transcribe-canonical.ts)             | One-shot canonical transcription with caller-supplied PCM and model options                             | Loading, inference and cleanup through the public helper                                       |
| [transcribe-whisper.ts](transcribe-whisper.ts)                 | Whisper family and task options                                                                         | Runtime API recipe; requires compatible local or remote model assets                           |
| [transcribe-medasr.ts](transcribe-medasr.ts)                   | LASR CTC family through a branded preset                                                                | Runtime API recipe                                                                             |
| [streaming-native.ts](streaming-native.ts)                     | Capability check, mono PCM chunks at an explicit sample rate, revisions, finalization and owned cleanup | Native streaming only when the selected model reports support; caller prepares the sample rate |
| [streaming.ts](streaming.ts)                                   | Repeated bounded windows through an offline session                                                     | Windowed simulation; not native model streaming                                                |
| [streaming-gate-config.ts](streaming-gate-config.ts)           | Shared VAD/gate configuration                                                                           | Configuration recipe; does not itself capture audio                                            |
| [detailed-and-native.ts](detailed-and-native.ts)               | Canonical and model-native transcript responses                                                         | Output contract recipe                                                                         |
| [choose-backend.ts](choose-backend.ts)                         | Explicit backend registration and selection                                                             | Backend selection recipe; availability is environment/model dependent                          |
| [transcribe-nemotron.ts](transcribe-nemotron.ts)               | Nemotron family setup                                                                                   | Model-specific recipe; check current validation status before relying on it                    |
| [whisper-splitgraph-local.mjs](whisper-splitgraph-local.mjs)   | Local four-graph Whisper export integration                                                             | Requires the matching exported graph set and sidecars                                          |
| [nemo-tdt-native-local.mjs](nemo-tdt-native-local.mjs)         | Explicit Node.js native CPU setup for NeMo TDT                                                          | Experimental native path; requires optional `onnxruntime-node` and local graphs                |

The library also exports browser capture, realtime-controller, TEN-VAD, FireRed-VAD and waveform primitives from its browser/realtime entry points. Those APIs require browser permissions and compatible browser assets. The companion Realtime application demonstrates their combined use with a live waveform and VAD timeline; see the [integration guide](../docs/INTEGRATION_GUIDE.md#browser-capture-and-vad).

Native streaming, windowed offline inference and VAD-driven microphone transcription are distinct behaviors. See [Streaming and deployment](../docs/INTEGRATION_GUIDE.md#choose-a-streaming-contract) before choosing a recipe.
