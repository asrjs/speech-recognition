## 2025-03-01 - Optimizing Whisper Seq2Seq Token Extraction\n**Learning:** In transcription models, chained `.map()` and `.filter()` operations on hot token arrays cause redundant iterations and intermediate array allocations. Extracting these into a single loop reduces memory pressure and CPU cycles.\n**Action:** Replaced chained array methods with a single loop in Whisper Seq2Seq token extraction.
