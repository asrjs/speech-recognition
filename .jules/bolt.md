## 2024-05-23 - `??` operator performance with TypedArrays
**Learning:** In V8 (Node/Bun/Chrome), using the nullish coalescing operator (`??`) inside tight inner loops dealing with TypedArrays significantly degrades performance compared to using the non-null assertion operator (`!`) or a type cast `as number`. This happens even when bounds are implicitly safe. Memory guidelines state: `In V8 (Node/Bun/Chrome), using the nullish coalescing operator (??) inside tight inner loops dealing with TypedArrays significantly degrades performance compared to using the non-null assertion operator (!). When bounds are known to be safe, prefer ! to preserve performance.`
**Action:** When working with TypedArrays in hot loops (like in DSP or math functions such as `argmax`), prefer non-null assertions (`!`) or type casts (`as number`) over nullish coalescing (`??`) to maintain peak performance, because `tsconfig.json` enforces `noUncheckedIndexedAccess: true`.
