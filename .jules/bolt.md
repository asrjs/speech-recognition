## 2024-04-11 - V8 Engine Array Bounds Optimization
**Learning:** In V8 (Node/Bun/Chrome), using the nullish coalescing operator (`??`) inside tight inner loops dealing with TypedArrays significantly degrades performance compared to using the non-null assertion operator (`!`). Even when bounds checking isn't the bottleneck, the type guard logic generated by `??` causes major slowdowns.
**Action:** When bounds are implicitly safe in hot loops iterating over arrays/TypedArrays (like `argmax` functions), use `!` or cast `as number` instead of `??` to avoid V8 pipeline de-optimizations.
