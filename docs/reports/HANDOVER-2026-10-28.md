  `f88260fa0777fe0868dda6df85d1a98f012a4a7a`. Preferred profile is FP16

### Large model Blob fix found during real inference testing

Initial Parakeet Hub-source acceptance failed with `ERR_BLOB_OUT_OF_MEMORY`
before inference. The shared asset code accumulated cloned chunks and constructed
a giant `Blob`. A discriminator using the same 1,238,960,452-byte encoder failed
on that path, while native `Response.blob()` and the bounded stream bridge read
the Blob successfully. `src/io/handles.ts` now bridges the async iterator through
a backpressured `ReadableStream` into `Response(...).blob()`, preserving progress,
chunk ownership, cancellation/error handling and content type. IO regression
tests were added. Four subsequent real-model file flows passed.
